# Fonts Directory

Place the licensed font files here:
- `public/fonts/aisling.woff2` (Aisling - Display typography)
- `public/fonts/cyberway-riders.woff2` (Cyberway Riders - Interface & Match typography)

### Font Format & Licensing
- Ensure files are in WOFF2 format for optimal browser delivery.
- If font files are not yet provided, modern high-end esports Google Font fallbacks (`Cinzel`/`Trajan Pro` for display and `Rajdhani`/`Chakra Petch` for interface) are automatically active via CSS rules until the local font binaries are uploaded to this folder.
